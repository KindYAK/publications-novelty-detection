## 1. Основной датасет: arXiv v3

**Что**: Все статьи из 4 категорий arXiv за 2016–2026.

**Категории**: cs.CL (72K), cs.LG (162K), cs.CV (146K), cs.AI (62K).

**Как собирали**:
1. arXiv API — запросы по `submittedDate` с разбиением по кварталам (Q1–Q4), чтобы обойти лимит пагинации в 10K
2. Semantic Scholar `/paper/batch` — обогащение цитированиями, батчами по 450 ID
3. Полные тексты — асинхронный пайплайн:
   - ar5iv HTML (91% покрытие, быстро)
   - arXiv PDF через PyMuPDF (7% дополнительно)
   - LaTeX-исходники (2%)
   - Фикс суффикса `v1` для старых статей

**Скрипты**: `collect_v3_comprehensive.py`, `collect_fulltext.py`

**Формат**: `dataset_v3.parquet` (442K строк), тексты в `fulltext/*.txt`

## 2. ACL Anthology — все NLP-конференции

**Что**: Все статьи из ACL/EMNLP/NAACL/EACL/COLING/TACL/LREC/Findings/воркшопов, которых нет в arXiv. Включает ландмарки по эмбеддингам (Word2Vec, GloVe, Flair и др.).

**Как собирали**:
1. HuggingFace датасет `ACL-OCL/acl-anthology-corpus` (parquet, 514 МБ) — 59 408 статей до 2022 г., уже с полным текстом (GROBID-экстракция из PDF)
2. Python-пакет `acl-anthology` — 8 658 статей за 2023–2025, PDF скачаны с aclanthology.org и обработаны PyMuPDF
3. Целевой поиск статей по эмбеддингам (ключевые слова: `word embedding`, `sentence embedding`, `contextual embedding`, `dense retrieval`, `BERT`, `SimCSE`, ...) — 3 904 статьи через HuggingFace + `acl-anthology` + Semantic Scholar
4. 10 ландмарков до 2016 (Word2Vec, GloVe, Bahdanau Attention, Skip-Thought, Flair)
5. Semantic Scholar — обогащение цитированиями через `CorpusId` (93.1% verified)

**Дедупликация**: по нормализованному заголовку (lowercase, только буквы+цифры) против arXiv-датасета и между источниками.

**Скрипты**: `collect_acl_all.py`, `collect_embeddings_acl.py`

**Формат**: `acl_all.parquet` (71K строк), тексты в `acl_all_fulltext/`

## Колонка `citation_status`

Для ACL-датасета введена колонка, позволяющая отличить настоящий ноль цитирований от отсутствия данных:

| Статус | Кол-во | Значение |
|--------|--------|----------|
| `verified` | 66 176 | SS подтвердил — если citations=0, это действительно 0 |
| `hf_verified` | 890 | Цитирования из HuggingFace корпуса (снэпшот ~2022) |
| `too_recent` | 3 486 | Статья 2024+, цитирования ещё не накопились |
| `recent_unverified` | 470 | Статья 2023, SS мог не проиндексировать |
| `ss_not_found` | 95 | SS не нашёл статью, цитирования ненадёжны |

**93.1%** статей имеют надёжные данные о цитированиях (`verified` + `hf_verified`).
